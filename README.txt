GovConnect (static frontend)

Open index.html in any browser. No build step or server needed.

Files
- index.html  page structure (Home, About Us, Product Gallery, Contact, Reviews)
- style.css   layout and the Light / Dark / Saffron themes
- script.js   services and exam data (SERVICES and EXAMS lists), theme toggle, search, reviews

Notes
- The theme choice and posted reviews are saved only in the visitor's browser (localStorage).
- The contact form sends nothing; connect it to a backend before real use.
- Guides marked v:1 in script.js were checked against official sites. Confirm the others on the official portals before publishing.
- Fonts load from Google Fonts; the page falls back to system fonts offline.
